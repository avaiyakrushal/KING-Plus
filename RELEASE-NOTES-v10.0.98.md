# KING Plus v10.0.98 — Me Profile Privacy (TEST)

- Me privacy choices save atomically to account preferences and public profile display metadata.
- “Allow people to find me” hides opted-out accounts from KING Plus Discover and People search cards.
- “Show entrance effects” is respected when this account joins a Party room.
- The online-status preference syncs, but this build has no global online indicator. Party room members remain visible to that room's participants.
- Older app versions and direct profile links may still show public profile information; these preferences do not replace server authorization.
- Agency and Owner Console visibility still require trusted server authorization. Profile settings cannot grant those privileges or change VIP, diamonds, or level.
- Cloud Function deployment remains required for live server-side functions.
