# Bolo Hi Me/Profile → KING Plus audit (v10.0.85)

| Me/Profile option | KING Plus path and behavior |
| --- | --- |
| About / Edit profile | Opens account profile details and editor |
| Gallery / Videos | Opens the existing account Moments gallery and on-device video manager |
| Share profile | Shares only a server-verified KING ID invitation |
| Likes | Loads this account's liked Moment records and live source posts; unlike removes the post from the page |
| Followers / Following / Friends | Opens the matching live social list |
| Visitors / Gift Wall / Notifications / Safety | Uses existing account-scoped visitor, gift, inbox, privacy and report pages |
| Favorite / Recent Party Rooms | Uses the existing saved and recent room screens |
| Family / Relationship / Collection | Opens the existing Community pages |
| Level / Medals / VIP | Unverified XP stays TEST-only, medals stay locked, and VIP requires verified Wallet data |

This adds working liked-post retrieval to the Me Profile option set. Server-backed profile video uploads, verified XP/reward progression, remaining Bolo Hi options, and signed-in cross-device QA are still open work.
