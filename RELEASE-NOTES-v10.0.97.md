# KING Plus v10.0.97 — Me Profile Privacy Progress (TEST)

- Me privacy choices now save atomically to the account preferences and public profile display metadata.
- “Allow people to find me” hides opted-out accounts from KING Plus Discover and People search cards.
- “Show entrance effects” is respected when this account joins a Party room; a disabled effect is not published in its room-member record.
- Existing direct profile links and older app versions may still show public profile information; these preferences do not replace server authorization.
- Agency and Owner Console visibility continue to require trusted server authorization. Client profile settings cannot grant those privileges or change VIP, diamonds, or level.
- Cloud Function deployment is still required for live server-side functions.
