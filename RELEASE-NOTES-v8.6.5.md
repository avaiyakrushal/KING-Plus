# KING Plus v8.6.5 — synchronized Memory + Domino

Based on v8.6.4.

- Adds a synchronized **Memory Duel** Party Room round. Every ready player receives the same shuffled 4-pair board, plays locally against that shared layout, and submits attempts/time as a score. Host/co-host finishes the round and the room sees the winner.
- Adds a synchronized **Domino Match** Party Room round. Everyone sees the same shared chain-end target and submits one matching tile; the room result lists correct winners.
- Memory and Domino now appear in the host/co-host synchronized round launcher in Room Multiplayer.
- Existing synchronized Tic Tac Toe, RPS, Dice, Pick Number, Coin, Wheel, Bingo, Slot, Reaction, High/Low, Sheep and Crazy Zoo remain unchanged.
- Party-room Online Ludo integration, gift catalog, Live 50 effects, bottom message composer/keyboard fixes, no-billing mode and TEST OTP remain unchanged.

Next stage: Werewolf, Spy and Draw & Guess need private/shared realtime game state beyond the current one-move round model.
