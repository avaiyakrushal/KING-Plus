# KING Plus v8.7.0 — Parity Core

This build starts the next broad Bolo Hi–style parity phase with original KING Plus implementation and branding.

- Added KING Parity Center inside Party Room.
- Added room-synchronized KTV Stage: members request songs; host/co-host can place a request on the shared room stage.
- Added PK Arena: Red/Blue team join events plus gift-backed shared score and moderator PK round state.
- Added Match Center using real public KING Plus profiles; cards open the existing rich profile flow.
- Added Party Stage scene chooser with Royal, KTV, PK, Galaxy, Festival, Ice, Neon, Love and Game themes.
- Added VIP & Rank center linked to the existing no-billing progression/cosmetics system and public profile ranking.
- Party Room now uses its premium gradient/glow renderer instead of the old fixed background; PK gets its own red/blue visual theme.
- Room badges now open VIP/Rank and Match.
- Expanded Party Tools and More menu with Parity Center, KTV Stage, PK Arena, Match, Party Stage and VIP Rank.
- Fixed a Tools grid bug where 29 labels were backed by only 27 icons.
- Firestore public profile rules now explicitly permit validated photoUrl so the v8.6.8 profile-photo cloud sync can work after the rules are deployed.
- No billing behavior is unchanged. Existing games, gifts, live emoji, rooms, moderation, Family and Relationship flows are preserved.

Important: this build does not copy Bolo Hi proprietary assets/code or claim exact 3D/Unity parity. It provides independent KING Plus equivalents.
