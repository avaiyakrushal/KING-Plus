# KING Plus v7.0.0 reference parity

This stage focuses on working KING Plus equivalents rather than inflating APK size.

## Working in KING Plus
- Auth foundation and searchable public profiles / KING ID
- Party lobby and room creation/opening
- 8/10/12 seat rooms, seat requests, invite/kick/ban, host/co-host, seat locks
- Room chat, replies, mentions, private chat, emoji/live emoji
- Gifts, quantities, gift chat cards, wall, history, ranking, lucky/wish tools
- Normal Level 1–99 and VIP 0–12 progression tied to gifting
- KTV/music/radio mic, Audio PK and Loop Mic queue
- Multi-video/voice room web flow
- Search people/rooms, Moments/Square, Family, Relationship/CP
- Collection/Backpack/Medals and daily free gift
- Playable lightweight games plus party game room flows
- Profile/edit profile, followers/following/friends, settings/safety

## Not copied from the reference APK
The reference APK bundles large proprietary/native components such as Unity/IL2CPP games, proprietary voice/video/beauty/filter engines and media assets. Those binaries/assets are not copied into KING Plus. Where feasible, KING Plus uses original lightweight implementations and Firebase-backed flows.
