# KING Plus v10.0.101 — Party events connected to live games

- Crazy Fruits and Lucky Slot open the shared Ready-player Slot Clash round.
- Chicken Run opens the shared Live Sheep Sprint round.
- Animal PK opens the shared Crazy Zoo round.
- Room Quiz is a host-started live room poll with four editable choices, shared voting and room-wide result totals.
- Party game templates open their matching KING Plus multiplayer game directly (Ludo, Bingo, Domino, Sheep, and Draw & Guess).
- Home continues to use the single Party lobby, which loads real live rooms instead of local sample rooms.
- No option grants diamonds, coins, XP, or VIP from local game results.

This is a TEST build. Third-party mobile games are not embedded, and this milestone does not claim complete Bolo Hi feature parity.
