# KING Plus v8.9.0 — Visual Parity Pro

This stage continues the remaining visual/function parity work with original KING Plus implementation.

- Adds an animated presentation panel to KTV, PK, Family, Rank, Gift and Arcade screens.
- KTV presentation now has an animated equalizer/microphone stage and a host/co-host Stop shared stage action.
- PK presentation gets a dedicated red/blue split arena with pulsing VS/fire/ice treatment.
- Family presentation gets an animated KING crest; Family Activity Feed now opens recent activity instead of posting immediately, with a separate Post Activity action.
- Rank presentation adds a podium visual and richer top-3 ranking cards.
- Gift presentation gets a cinematic gift/particle panel while retaining the existing 64-gift Party Shop and gift burst effects.
- Arcade gets a dedicated animated game presentation panel while preserving playable local/realtime games.
- Existing v8.8.1 keyboard, message-clear, equal chat bubble and equal gift-card fixes remain unchanged.
- No billing behavior is unchanged; no third-party proprietary assets/source are copied.
